# Beyond Guidance RMSE for Field Coverage Risk in Precision Agriculture

Reproducibility repository for the computational analysis underlying the manuscript **“Beyond Guidance RMSE for Field Coverage Risk in Precision Agriculture.”**

The study propagates measured lateral tractor-guidance errors into finite-field coverage consequences and examines why equal guidance RMSE can produce different spatial patterns of skip, overlap, outside-field application, and persistence.

## What this repository contains

- `src/` — the 21 analysis stages used for empirical characterization, spatial reconstruction, equal-RMS/common-marginal controls, geometric validation, persistence analysis, bootstrap estimation, and operational tolerance transfer.
- `tools/inspect_guidance_mat.py` — utility for inspecting the source MATLAB guidance dataset.
- `results/final_tables/` — curated numerical outputs supporting the manuscript's headline results.
- `results/final_figures/` — curated final analysis figures.
- `data/source/README.md` — instructions for obtaining the original open dataset.

The repository intentionally does **not** duplicate the full 65+ MB source dataset or hundreds of intermediate generated outputs. Those can be regenerated from the scripts.

## Source dataset

The empirical trajectories come from the open dataset accompanying:

**Gomez-Gil et al. (2026).** *Performance assessment of no-fee GNSS augmentation systems for tractor guidance*. **Computers and Electronics in Agriculture, 247**, 111612.

- Article DOI: https://doi.org/10.1016/j.compag.2026.111612
- Dataset DOI: https://doi.org/10.17632/xj3vp2w89y.1

Download the dataset and follow `data/source/README.md` before running Stages 01–03.

## Headline numerical outputs

For the evaluated dataset:

- 14 GNSS/augmentation configurations and 28 primary trajectories (passes 1 and 3).
- Canonical spatial grid: 0.20 m.
- 378 dependent unordered trajectory-pair combinations.
- Dataset-calibrated interior coefficient: **K ≈ 1.12** with configuration-cluster 95% CI **[1.10, 1.14]**.
- Dataset-calibrated boundary coefficient: **B ≈ 0.398** with 95% CI **[0.382, 0.412]**.
- Exact analytical-vs-polygon geometry closure: maximum absolute error approximately **9.49 × 10⁻15**.
- Multi-pass transfer relation:

```text
D_M = (R/W) C(M)
C(M) = ((M-1)/M) K + (2B/M)
```

These numerical coefficients are **dataset-specific calibration estimates**, not universal GNSS constants. The dimensionless framework is the transferable part of the work.

## Important interpretation

The 378 pairwise combinations are not 378 statistically independent observations. They are used as an exhaustive structural comparison because each trajectory participates in multiple pairs. Configuration-level uncertainty for the headline coefficients is handled separately through a cluster bootstrap that retains the paired pass structure within each of the 14 configurations.

The phase-design coefficient is obtained through relative-phase averaging for generic transfer when pass alignment is unspecified. Circular phase shifting is a computational averaging device; it is not an assumption that a physical field is periodic. Linear-domain persistence metrics are reported separately.
