# Source data

The analysis uses the published tractor-guidance dataset associated with:

Gomez-Gil et al. (2026), *Performance assessment of no-fee GNSS augmentation systems for tractor guidance*, Computers and Electronics in Agriculture, 247, 111612.

Dataset DOI: https://doi.org/10.17632/xj3vp2w89y.1
Article DOI: https://doi.org/10.1016/j.compag.2026.111612

Download the dataset from the DOI above and place the guidance-test files here using this structure:

```text
data/source/
└── 2_Guidance_tests/
    ├── 2A_Guidance_tests_data.mat
    ├── 2B_Guidance_tests_Figures.m
    ├── 2C_Guidance_tests_Table 2.m
    └── 2D_Data_Dictionary_Guidance_test_data.pdf
```

The original dataset is not duplicated in this repository. Please cite the original authors and dataset when reusing it.
